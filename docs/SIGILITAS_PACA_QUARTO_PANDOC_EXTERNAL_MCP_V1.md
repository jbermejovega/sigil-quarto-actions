# PACA Quarto/Pandoc external MCP exposition

This source-bound interface exposes PACA Quarto and PACA Pandoc projections, the whole typed worktree, embodied STATIK memory, and every KOKOMPI agent registered in the current Koko SDK session.

The stable operation surface is `DESCRIBE`, `READ`, `VALIDATE`, and `PLAN`. Declaring the interface starts no MCP server and grants no GitHub or runtime authority.

The parametric rule `RepositoryType[R] -> LiveSigilbookType[R]` preserves repository identity. It defines how admitted repositories are typed; it does not claim that every GitHub repository has already been enumerated. `HyperJarraJauriaType` indexes distinct live SIGILBOOK members without fusing them.
