# PACA Quarto editorial factorization V1

`PACA_QUARTO_EDITORIAL_FACTORIZATION_V1` is a source-bound, static editorial
contract for projecting a GitHub repository into a typed compositional
SIGILBOOK. It describes effect plans but executes no renderer, syscall,
workflow, network request, publication, Git write, or quantum program.

## Factorization

```text
Git repository@head
→ primitive typed sections
→ incidence cells and restriction arrows
→ HyperJarra contextual indices
→ cochain-degree annotations
→ bounded editorial causal DAG
→ PACA Pandoc AST / PACA Quarto projection
→ immutable artifact plan
→ PACADEX/MCP resource
→ Safe Replay receipt
```

The incidence partial order, causal DAG order, and cochain grading are distinct.
Alignment is carried by explicit section and witness fields; no total order of
cohomology is asserted. Local and global sections keep distinct identities.

## Algebraic reindexing

ZX-calculus, Quipper, and OpenQASM 3 enter through separate typed ports. Each
port records domain, codomain, source index, target HyperJarra index, and a
semantic witness. They are not silently identified and no physical
equivalence is inferred.

The design follows the OpenQASM 3 typed imperative circuit surface, Quipper's
higher-order functional circuit generation, and ZX-calculus graph rewriting:

- https://openqasm.com/
- https://arxiv.org/abs/1304.3390
- https://quantum-journal.org/papers/q-2020-06-04-279/

For local/global structure, restriction maps carry incidence and semantic
witnesses; cohomology is used as an obstruction/consistency layer, not as a
synonym for causal execution order. Cellular sheaf references:

- https://link.springer.com/article/10.1007/s41468-019-00038-7
- https://www2.math.upenn.edu/~ghrist/preprints/tarski.pdf

## Universal abstract and trope types

`PluralTyped`, `QUNOTyped`, `SacredTyped`, `TropeTyped`, and `MemeTyped` are distinct flavors
of `UniversalAbstractType`. Every flavor requires an explicit propagation
witness into an Allegoric Kernel.

`TropeType` is persistent typed SIGIL fiction: it carries a source digest,
monotonic checkpoint, and allegoric relation witness. Persistence does not
promote fiction to fact, theorem, proof, or runtime evidence.

`MemeType` is a persistent virtual-media type adjacent to, but distinct from,
`QUNOTyped`. It carries a substrate-independent-within-model media witness, an
abstract solitonic-kink-pulse witness, and a universe-relative constant of
motion. The local and global numerical presentations are related by an
explicit restriction/conservation witness. The number is not asserted to be a
literal constant shared by every physical universe, and no physical kink is
inferred.

## Effects and truth boundary

The only planned POSIX-aligned effects are read/stat/list plus confined artifact
write and atomic rename. `EXEC`, network, publication, shell, and Git writes are
forbidden. Missing witnesses produce `HOLD`; identity collapse, reversed
restriction, causal cycles, unconfined writes, or authority amplification
produce `REJECT`.
