# SIGILITAS livecoded worktree piBI session

This carrier projects a GitHub worktree observation through four identity-distinct phases:

1. `INKED`: source-bound digest, provenance, and receipt.
2. `LINKED`: typed `ProjectType -> WorkTreeType -> Event -> PACADEX` edges.
3. `KINKED`: a typed transition cell between parent and head. It makes no claim about physical curvature or a physical kink.
4. `TWINKED`: STATIK and DYNAMIK projections share one omega witness while retaining distinct bearers.

The session tree uses generalized bunched typing. Additive `&` shares project and provenance context between INKED and LINKED. Multiplicative `*` keeps KINKED transition resources separate from TWINKED projection resources.

`PacaPanicTyped` is a receipt value, never ambient exception authority. Missing evidence, an unaccepted event, or a missing parent checkpoint yields `HOLD`. Provenance drift, identity collapse, causal cycles, and capability amplification yield `REJECT`. Every panic preserves the checkpoint and records `repository_mutated=false` and `runtime_authority=false`.

An outer PACADEX `ADMIT` is possible only when the livecoded session also admits. An inner `HOLD` or `REJECT` is therefore never hidden by the accepted GitHub event classification.
